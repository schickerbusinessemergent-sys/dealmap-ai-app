# DealMap development environment

A Next.js app starter with a GitHub Codespaces/VS Code dev container. See [TERMINAL-SETUP.md](./TERMINAL-SETUP.md) for cloud and local terminal setup, environment variables, and run commands.

```bash
npm install
npm run dev
```

Open http://localhost:3000 for local development. External Supabase, Stripe, and AI credentials are not included. Use Stripe test mode only during development. Do not commit credentials.
